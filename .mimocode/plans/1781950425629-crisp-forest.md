# Fix: iOS App Blank Page

## Root Cause

`index.html` references assets at `./assets/index-DmNetiRB.js` and `./assets/index-De4NRjee.css`, but xcodegen flattens all files from `UtralTodo/www/` into the bundle root. The `assets/` subdirectory is lost — JS/CSS files end up at `UtralTodo.app/index-DmNetiRB.js` instead of `UtralTodo.app/assets/index-DmNetiRB.js`.

## Fix

Change `apps/mobile/vite.config.ts` to set `assetsDir: ''` so vite outputs JS/CSS alongside `index.html` (at root level), matching xcodegen's flat bundle structure.

## Files to Modify

- `apps/mobile/vite.config.ts` — add `build: { assetsDir: '' }`

## Verification

1. Run `pnpm ios:dev`
2. App should load and render the Today page (not blank)
