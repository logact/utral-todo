# Fix: Today dashboard UI flickering from irrelevant DB change events

## Root Cause

`useDbChangeRefresh` (`apps/desktop/src/hooks/useDbChangeRefresh.ts:14-16`) triggers a full data refresh on **every** `db:changed` and `sync:remote-applied` event, regardless of which table changed.

When the Pluse timer auto-advances, `updateTimerSession()` in `apps/desktop/src/db/timerSessions.ts:84` dispatches a `db:changed` event with `detail: { table: 'timerSessions' }`. The hook ignores the table name and calls `refresh()`, which re-fetches all Today page data (todos, overdue, inProgress, suggested, goals) from IndexedDB. This causes the UI to flicker/reset.

The same problem exists for `sync:remote-applied` — the event carries `detail: { table, operation, recordId }` but the handler discards it.

## Plan

### Step 1: Add table filtering to `useDbChangeRefresh`

**File:** `apps/desktop/src/hooks/useDbChangeRefresh.ts`

- Accept a new optional `tables?: string[]` parameter in options
- In the event handlers, read `event.detail?.table` and skip the refresh if `tables` is provided and the changed table is not in the list

```ts
export function useDbChangeRefresh(
  refresh: () => void,
  options?: { delay?: number; skipInitial?: boolean; tables?: string[] }
)
```

Handler logic:
```ts
const handler = (event: Event) => {
  const detail = (event as CustomEvent).detail;
  if (tables && detail?.table && !tables.includes(detail.table)) return;
  clearTimeout(timeout);
  timeout = setTimeout(() => refresh(), delay);
};
```

### Step 2: Pass relevant tables in `useTodayData`

**File:** `apps/desktop/src/hooks/useTodos.ts` (line 198)

Change:
```ts
useDbChangeRefresh(refresh);
```
To:
```ts
useDbChangeRefresh(refresh, { tables: ['todos', 'relations', 'repeatOccurrences', 'pluses', 'actionEdges', 'plans'] });
```

This prevents `timerSessions` changes from triggering a Today page refresh.

### Step 3: Apply same fix to other hooks using `useDbChangeRefresh`

- `useTodos()` (line 40) — refreshes on all todos changes → `{ tables: ['todos', 'relations', 'repeatOccurrences'] }`
- `useTodaysTodos()` (line 143) — same as useTodayData → `{ tables: ['todos', 'relations', 'repeatOccurrences', 'pluses', 'actionEdges', 'plans'] }`
- `useScheduleTodos()` (line 295) — relevant tables: `['todos', 'relations', 'repeatOccurrences']`
- `useTodoLogs` in `apps/desktop/src/hooks/useTodoLogs.ts` (line 17) → `{ tables: ['todoLogs', 'todos'] }`
- `useRelations` in `apps/desktop/src/hooks/useRelations.ts` (lines 22, 58) → `{ tables: ['relations', 'todos'] }`
