# Plan: Extract Schema into Common Package

## Goal
Extract shared data model interfaces and enums into `@utral/types` as the single source of truth, keeping database-specific Drizzle table definitions local to each app.

## Current State
- **`packages/types/src/index.ts`**: TypeScript interfaces (Todo, TodoRelation, TodoLog, ActionEdge, Plan, Pluse, RepeatOccurrence) + enums + HLC type
- **`apps/server/src/db/schema.ts`**: Drizzle PostgreSQL tables (pgTable) + relations
- **`apps/desktop/src/db/schema.ts`**: Drizzle SQLite tables (sqliteTable) + row↔entity converters

## Implementation

### Step 1: Reorganize `@utral/types` package structure

Create dedicated files for better separation:

```
packages/types/src/
  index.ts          # barrel export (keep as entry point)
  enums.ts          # TodoStatus, Priority, NodeType, TaskPattern, GoalStatus, etc.
  hlc.ts            # HLC interface
  entities.ts       # Todo, TodoRelation, TodoLog, ActionEdge, Plan, Pluse, RepeatOccurrence
  sync.ts           # SyncConfig, SyncResult, Device, Label, etc.
  repeat.ts         # (existing - keep as-is)
  timeSlots.ts      # (existing - keep as-is)
  today.ts          # (existing - keep as-is)
```

**Files to create:**
- `packages/types/src/enums.ts` - Move all type aliases from index.ts
- `packages/types/src/hlc.ts` - Move HLC interface
- `packages/types/src/entities.ts` - Move entity interfaces
- `packages/types/src/sync.ts` - Move sync-related types

### Step 2: Update `packages/types/src/index.ts`

Change to barrel re-exports:
```ts
export * from './enums.js';
export * from './hlc.js';
export * from './entities.js';
export * from './sync.js';
export * from './repeat.js';
export * from './timeSlots.js';
export * from './today.js';
```

### Step 3: Update server schema imports

**File: `apps/server/src/db/schema.ts`**

No changes needed - server already doesn't import from `@utral/types` for its Drizzle definitions. The server uses its own pgTable definitions which map to PostgreSQL types directly.

### Step 4: Update desktop schema imports

**File: `apps/desktop/src/db/schema.ts`**

Already imports from `../types` which re-exports from `@utral/types`. No changes needed to import paths.

### Step 5: Update build command

Add `@utral/types` build to the build chain in CLAUDE.md:
```bash
pnpm --filter @utral/types build && pnpm --filter @utral/sync build
```
