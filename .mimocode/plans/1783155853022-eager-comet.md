# Investigation: Expo App Not Auto-Updating After Sync

## Root Cause

The emitter in `apps/expo-app/src/lib/sync.ts:63-73` has **two bugs**:

### Bug 1: Query key mismatch for singular detail pages
The emitter invalidates `queryKey: ['todos']` (plural), but the todo detail page uses `queryKey: ['todo', id]` (singular). In React Query v5, `invalidateQueries(['todos'])` only invalidates keys that **start with** `['todos']` — it does NOT match `['todo', id]`. Same issue with `pluses` vs `pluse`.

| Table | Emitter invalidates | UI uses | Match? |
|-------|-------------------|---------|--------|
| todos | `['todos']` | `['todos']`, `['todos', 'today']`, etc. | ✅ |
| todos (detail) | `['todos']` | `['todo', id]` | ❌ |
| pluses | `['pluses']` | `['pluses']` | ✅ |
| pluses (detail) | `['pluses']` | `['pluse', id]` | ❌ |
| timeSlots | `['timeSlots']` | `['timeSlots']` | ✅ |
| todoRelations | (missing) | — | — |
| todoLogs | (missing) | — | — |
| actionEdges | (missing) | — | — |
| plans | (missing) | — | — |
| repeatOccurrences | (missing) | — | — |

### Bug 2: 5 of 8 canonical tables have no emitter handler
`todoRelations`, `todoLogs`, `actionEdges`, `plans`, `repeatOccurrences` — if any UI component queries these via React Query, remote changes will never trigger a refresh.

## Fix

**File**: `apps/expo-app/src/lib/sync.ts` lines 63-73

Replace the emitter with a comprehensive version that:
1. Invalidates `['todo', id]` when `todos` table changes (covers the detail page)
2. Invalidates `['pluse', id]` when `pluses` table changes (covers the detail page)
3. Adds handlers for all 8 canonical tables

```ts
emitter: {
  emitRemoteApplied: (table: string, operation: string, recordId: string) => {
    switch (table) {
      case 'todos':
        queryClient.invalidateQueries({ queryKey: ['todos'] });
        queryClient.invalidateQueries({ queryKey: ['todo', recordId] });
        break;
      case 'pluses':
        queryClient.invalidateQueries({ queryKey: ['pluses'] });
        queryClient.invalidateQueries({ queryKey: ['pluse', recordId] });
        break;
      case 'timeSlots':
        queryClient.invalidateQueries({ queryKey: ['timeSlots'] });
        queryClient.invalidateQueries({ queryKey: ['todos'] });
        break;
      case 'todoRelations':
      case 'todoLogs':
      case 'actionEdges':
      case 'plans':
      case 'repeatOccurrences':
        queryClient.invalidateQueries({ queryKey: ['todos'] });
        break;
    }
  },
},
```
