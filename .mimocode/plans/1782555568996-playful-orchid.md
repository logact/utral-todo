# Desktop: Refactor Storage from Dexie to SQLite + Drizzle ORM

## Overview

Replace Dexie (IndexedDB) with Drizzle ORM over `@tauri-apps/plugin-sql` (SQLite). Fresh start — no data migration from IndexedDB. The sync engine's separate `sync.db` stays unchanged.

## Strategy

Use `drizzle-orm/sqlite-proxy` — Drizzle's async callback driver. Wrap `@tauri-apps/plugin-sql` into the proxy callback interface. This avoids writing a full Drizzle driver adapter while getting full Drizzle query builder support.

## Key Decisions

- **Driver**: `drizzle-orm/sqlite-proxy` with a wrapper around `@tauri-apps/plugin-sql`
- **Schema init**: Raw SQL DDL in `initDatabase()` (like expo-app pattern), since we can't use `drizzle-kit push` with Tauri's plugin
- **HLC storage**: Separate columns (`createdAtWall`, `createdAtCounter`, `createdAtNode`) — TypeScript still uses `{wall, counter, node}` objects, schema maps between them
- **DB path**: `sqlite:utral-todo.db` (unified single DB replacing IndexedDB)
- **No sync queue in main DB** — sync engine keeps its separate `sync.db`

### Step 3: Create SQLite Proxy Wrapper

**New file**: `apps/desktop/src/db/drizzle-adapter.ts`

```ts
import Database from '@tauri-apps/plugin-sql';
import { drizzle } from 'drizzle-orm/sqlite-proxy';
import * as schema from './schema';

let tauriDb: Database | null = null;

async function getTauriDb(): Promise<Database> {
  if (!tauriDb) {
    tauriDb = await Database.load('sqlite:utral-todo.db');
  }
  return tauriDb;
}

export const db = drizzle(async (sql, params, method) => {
  const database = await getTauriDb();
  
  // @tauri-apps/plugin-sql uses $1 placeholders — Drizzle sqlite-proxy also uses $1
  if (method === 'run') {
    const result = await database.execute(sql, params);
    return { rows: [[result.rowsAffected]] };
  }
  
  // method === 'all' | 'get' | 'values'
  const rows = await database.select(sql, params);
  // Convert object rows to array rows for Drizzle
  if (method === 'get') {
    return { rows: rows.length > 0 ? [Object.values(rows[0])] : [] };
  }
  return { rows: rows.map(r => Object.values(r)) };
}, { schema });
```

Key points:
- `@tauri-apps/plugin-sql` uses `$1` placeholder syntax (same as Drizzle's sqlite-proxy)
- `database.select(sql, params)` returns `{[col: string]: any}[]` — we convert to `any[][]` for Drizzle
- `database.execute(sql, params)` returns `{rowsAffected: number}` — we wrap in rows array
- Lazy-load the Tauri DB connection on first query

### Step 6: Rewrite Each DB Module

Transform Dexie API calls to Drizzle queries. All function signatures stay the same.

**Translation patterns:**

| Dexie | Drizzle |
|-------|---------|
| `db.todos.add(todo)` | `await db.insert(todos).values(todo)` |
| `db.todos.get(id)` | `(await db.select().from(todos).where(eq(todos.id, id)).limit(1))[0]` |
| `db.todos.update(id, {x: 1})` | `await db.update(todos).set({x: 1}).where(eq(todos.id, id))` |
| `db.todos.filter(fn).toArray()` | `await db.select().from(todos)` + `.where()` + client-side filter |
| `db.todos.where('col').equals(val)` | `db.select().from(todos).where(eq(todos.col, val))` |
| `db.todos.where('col').between(a,b).and(fn)` | `db.select().from(todos).where(and(gte(todos.col,a), lte(todos.col,b)))` + `.where()` |
| `db.todos.toArray()` | `await db.select().from(todos)` |
| `db.todos.clear()` | `await db.delete(todos)` |
| `db.todos.count()` | `(await db.select({c: count()}).from(todos))[0].c` |
| `db.todos.bulkPut(records)` | `await db.insert(todos).values(records).onConflictDoUpdate({target: todos.id, set: ...})` |
| `db.transaction('rw', ...)` | `await db.transaction(async (tx) => { ... })` |
| `db.todos.where('col').equals(val).and(fn).toArray()` | `db.select().from(todos).where(and(eq(todos.col, val)))` + `.where()` |
