# Plan: Extract Common Models + Align Expo Schema

## Problem

Model interfaces are duplicated across apps. `@utral/types` only defines `Todo` and `RepeatOccurrence`. Desktop re-defines 6 interfaces locally. Expo uses ISO strings for timestamps (mismatch with HLC types) and is missing 5 tables.

## Changes

### 1. Add missing interfaces to `packages/types/src/index.ts`

Move from `apps/desktop/src/types/index.ts`:
- `TodoRelation`, `TodoLog`, `ActionEdge`, `Plan`, `Pluse`, `TimerSession`

All use existing `HLC` type.

### 2. Simplify `apps/desktop/src/types/index.ts`

Remove 6 local interface definitions + duplicate `HLC` type. Keep `@utral/sync-share` re-exports.

### 3. Align expo schema to desktop

**Add missing tables** to `apps/expo-app/src/db/schema.ts`:
- `todoRelations`, `todoLogs`, `actionEdges`, `plans`, `repeatOccurrences`

**Change timestamp columns** from ISO strings to HLC columns:
- `created_at` (text) → `created_at_wall` (integer), `created_at_counter` (integer), `created_at_node` (text)
- Same for `updated_at`, `deleted_at`

**Update expo database.ts** to use `@utral/types` interfaces instead of `$inferSelect`.

### 4. Update expo raw SQL migrations

Update `apps/expo-app/src/db/index.ts` CREATE TABLE statements to match new schema.
