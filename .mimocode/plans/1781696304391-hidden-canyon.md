# Plan: Add Built-in Summarization Recurring Tasks

## Summary
Add 6 system-level recurring tasks that serve as daily reminders for planning and summarization routines. These tasks are created automatically, visible to users, but protected from deletion/modification.

## The 6 Built-in Tasks

| Title | Schedule | ID |
|-------|----------|-----|
| Day Startup Plan | Daily 6:00 | `system:day-startup` |
| Morning Summary | Daily 12:00 | `system:morning-summary` |
| Afternoon Startup Plan | Daily 13:00 | `system:afternoon-startup` |
| Afternoon Summary | Daily 17:00 | `system:afternoon-summary` |
| Evening Startup | Daily 19:00 | `system:evening-startup` |
| Evening Summary | Daily 21:30 | `system:evening-summary` |

## Implementation Steps

### Step 1: Add `isSystemTask` to Prisma schema
**File:** `apps/server/prisma/schema.prisma`

Add to the Todo model (after `isRootGoal`):
```prisma
isSystemTask    Boolean?       @default(false)
```

Run `pnpm db:generate` to update Prisma client.

### Step 2: Add `isSystemTask` to shared types
**File:** `packages/types/src/index.ts`

Add to `TodoBase` interface (after `isRootGoal`):
```typescript
isSystemTask?: boolean;
```

### Step 3: Update Dexie schema (v41)
**File:** `apps/desktop/src/db/database.ts`

Add `db.version(41)` with:
- Add `isSystemTask` to todos store indexes
- Migration: seed the 6 system tasks if they don't exist

### Step 4: Add protection logic (desktop)
**File:** `apps/desktop/src/db/todos.ts`

- In `updateTodo()`: throw if `existing?.isSystemTask`
- In `deleteTodo()`: throw if `todo?.isSystemTask`

### Step 5: Add protection logic (server)
**File:** `apps/server/src/routes/todos.ts`

- In `PATCH /:id`: check if todo is system task, return 403
- In `DELETE /:id`: check if todo is system task, return 403
- In `PATCH /:id/repeat-rule`: check if todo is system task, return 403

### Step 6: Seed system tasks on server startup
**File:** `apps/server/src/index.ts`

Add `seedSystemTasks()` function called during startup (after migrations). Idempotent: checks if system tasks exist before creating.

### Step 7: Seed system tasks in Dexie migration
**File:** `apps/desktop/src/db/database.ts`

In the v41 upgrade, create the 6 system tasks with daily repeat rules if they don't exist.

## Critical Files
- `apps/server/prisma/schema.prisma` - Add `isSystemTask` field
- `packages/types/src/index.ts` - Add `isSystemTask` to TodoBase
- `apps/desktop/src/db/database.ts` - Dexie v41 migration + seed
- `apps/desktop/src/db/todos.ts` - Desktop protection logic
- `apps/server/src/routes/todos.ts` - Server protection logic
- `apps/server/src/index.ts` - Server startup seeding
