# Plan: Native macOS Notifications via UNUserNotificationCenter

## Problem
Notifications don't work on macOS. The `tauri-plugin-notification` uses `notify-rust` which defaults to the deprecated `NSUserNotificationCenter` API (silently fails on modern macOS). Previous attempts with `osascript` send notifications under "Script Editor", not the app.

## Solution
Enable `notify-rust`'s `preview-macos-un` feature which switches to the modern `UNUserNotificationCenter` API. Cargo feature unification means the Tauri plugin's `notify-rust` dependency will also use this backend.

## Changes

### 1. `src-tauri/Cargo.toml` (already done)
Keep `notify-rust = { version = "4", features = ["preview-macos-un"] }` — this was already added.

### 2. `src-tauri/src/lib.rs` — Remove all osascript code
- **`send_notification`** (line 205-241): Remove the `#[cfg(target_os = "macos")]` osascript block. Use `_app.notification().builder().title().body().show()` on all platforms.
- **`timer_schedule`** (line 164-203): Remove the `#[cfg(target_os = "macos")]` osascript block. Use `app.notification().builder().title().body().show()` on all platforms.
- **`setup` block** (line 276-291): Remove osascript test notification. Use `app.handle().notification().builder().show()` on all platforms.

### 3. `src-tauri/Entitlements.plist` — No changes needed
Keep current non-sandboxed entitlements. `UNUserNotificationCenter` works fine without sandbox.

## Verification
1. `cargo check` in `src-tauri/` to verify compilation
2. `pnpm tauri:build` to build the app
3. Open the app — a "Notifications are enabled" notification should appear immediately
4. Check **System Settings > Notifications** — the app "utral-todo-desktop" should now appear in the list
5. Trigger a timer in PluseRun — notification should appear under the app name
